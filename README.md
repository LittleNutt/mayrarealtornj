# MayraRealtorNJ.com

Static landing page for Mayra Galarza, REALTOR® with eXp Realty.

## Edit Content

- Contact details, social links, form endpoint, and featured listings live in `assets/js/script.js`.
- Mayra's portrait is stored at `assets/images/mayra-galarza.jpg`.
- Page styling lives in `assets/css/style.css`.

## Run Locally

Open `index.html` in a browser. No framework, package manager, or build step is required.
